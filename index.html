What broke and how I fixed it

Real problems from building the lab, and how I tracked each one down.

Zabbix said the switch was down

ProofSNMP data was still coming in, so the switch was up and something was blocking ping.

FixMy own ACL. One line permitting ping from the Zabbix server only.

No internet on day one

Proofshow ip route showed no gateway of last resort.

FixThe default route got dropped while pasting over a 9600-baud console. Re-added it.

DHCP handed out 255.0.0.0

Proofipconfig /all on the PC showed the wrong mask.

FixThe scope wizard defaults to /8 for 10.x addresses. Rebuilt the scope as /24.

IoT device got no IP

Proofshow interfaces status proved the switch was set up right.

FixpfSense's DHCP server on the IoT interface was off. Turned it on.
